Project Overview & Roadmap

About Second Life

Second Life is a prototype platform designed to help people make more informed decisions about old and damaged products.

REVIEW 1 (CURRENT)

Frontend Prototype

Focuses on responsive user experience, circular decision modeling, dynamic UI feedback, and client-side data simulation.

TECHNOLOGY USED:

  • Semantic HTML5
  • CSS3 (Flexbox & Grid)
  • Vanilla JavaScript (ES6+)
  • Browser LocalStorage API

KEY CAPABILITIES:

  • ✓ Multi-parameter assessment decision engine
  • ✓ Financial cost savings calculation
  • ✓ Dynamic visual lifecycle path generator
  • ✓ Customized 4-step action plans
  • ✓ Local history persistence
REVIEW 2 & 3 (ROADMAP)

Full Stack Platform

In subsequent college project reviews, the frontend will be seamlessly integrated with backend services and databases.

FUTURE CAPABILITIES & MODULES:

  • Database & Backend: REST API layer to store structured users, products, and assessments.
  • Repair Centre Directory: Interactive map & verified directory to book authorized repair services.
  • Recycling Centre Directory: Authorized e-waste drop-off locations and certified recyclers.
  • User Accounts & Authentication: Personal dashboards, item tracking, and maintenance reminders.
  • Environmental Impact Tracking: Calculated CO₂ footprint prevented and e-waste kilograms diverted.
